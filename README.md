# ケルビン・ヘルムホルツ不安定 波 Canvas

速度差を持つ2流体層の界面にKH不安定が成長する様子をアニメーション。

## 機能
- 上層(U₁)・下層(U₂)速度スライダー
- 波数(k)・初期擾乱振幅スライダー
- 界面に正弦波擾乱を与えてKH不安定の成長をアニメーション
- 200個のパーティクルで上層(オレンジ)・下層(青)を表示
- 成長率 σ = k|ΔU|/2 計算・表示
- 成長段階表示（初期擾乱→成長中→非線形域→渦巻き形成）
- 一時停止/リセットボタン

## 技術
- 静的SPA（単一index.html）
- Tailwind CSS CDN
- Canvas + requestAnimationFrame
- localStorage不使用
